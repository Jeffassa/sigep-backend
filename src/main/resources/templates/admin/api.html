Comment s'en servir

Envoyez votre clé dans l'en-tête X-API-Key. L'API est en lecture seule.

curl -H "X-API-Key: VOTRE_CLE" \
     https://sigep.store/api/public/seances?debut=2026-09-01&fin=2026-09-30
